## Workflow

1. Check staging: Run `git status`
   - If nothing staged: run `git add` for relevant changes

2. Analyze changes: Run `git diff --cached`
   - If multiple unrelated changes detected: split into separate commits
   - Otherwise: proceed to commit

3. Create commit message:
   - Use CONVENTIONAL COMMIT format:

      ```text
      <type>: <description>
      [optional body]
      ```

   - Type: feat, fix, docs, style, refactor, perf, test, chore
   - Description: <72 chars, use imperative mood
   - Body: If provided, keep it precise and concise
   - IMPORTANT: Do NOT add any "Generated with", "Co-Authored-By", or tool attribution text in the message body

4. Handle AI-generated trailer:
   - If $ARGUMENTS equals to "ai": add trailer via `-m "AI-Generated-By: [Coding Tool Name]"`
   - If $ARGUMENTS is empty or any other value, **You must ask the user**: "Is this commit generated by AI?"
       - OPTION 1 - Yes: add trailer via `-m "AI-Generated-By: [Coding Tool Name]"`
       - OPTION 2 - No: complete the commit without trailer
