## 首次上传项目 # 1. 进入项目目录 cd 项目目录 # 2. 初始化 Git 仓库 git init # 3. 查看修改状态 git status # 4. 暂存全部文件 git add . # 5. 创建本地 commit git commit -m "Initial commit" # 6. 将当前分支命名为 main git branch -M main # 7. 添加远端仓库 git remote add origin https://github.com/用户名/仓库名.git # 8. 检查远端地址 git remote -v # 9. 上传 main 分支并建立跟踪关系 git push -u origin main
